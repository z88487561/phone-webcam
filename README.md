# 手機攝影機 PWA

https://z88487561.github.io/phone-webcam/

把手機當成攝影機，並透過另一台手機或電腦即時觀看。專案是純前端 PWA，不需要自行架設應用程式後端。

## 功能

- 以 WebRTC 傳送即時影像與音訊，支援多台攝影機和多畫面檢視。
- 以 QR code 或配對連結配對；配對碼有效 5 分鐘且只能使用一次。
- 攝影機可設定動態偵測、忽略區域、事件前錄影、事件通知及錄影容量上限。
- 檢視器可拍照、切換鏡頭、控制支援的手電筒與縮放，並使用按住說話的對講功能。
- 支援離線快取應用程式外殼；錄影存放於瀏覽器 IndexedDB。

## 啟動

1. 將專案檔案部署至 HTTPS 網站，或在本機以 `localhost` 提供靜態檔案。
2. 在手機和檢視器裝置上，以最新版 Chrome、Edge 或 Safari 開啟網站。
3. 要安裝 PWA 時，使用瀏覽器的「加到主畫面」或「安裝應用程式」功能。

攝影機、麥克風、螢幕常亮等瀏覽器功能通常要求安全來源（HTTPS 或 `localhost`）。直接用 `file://` 開啟不適用。

本專案沒有附開發伺服器或建置指令；任何能提供靜態檔案的 HTTPS 主機均可部署。

## 配對與觀看

1. 在檢視器裝置開啟網站，選「當檢視器」，按「新增攝影機」顯示配對 QR。
2. 在攝影機裝置選「當攝影機」，按「掃描配對 QR」掃描；也可以用相機 App 掃描後開啟連結，或貼上配對連結。
3. 允許瀏覽器使用攝影機；如需收音、動態通知或對講，再允許相應的麥克風、通知權限。
4. 按「開始守候」。檢視器會在攝影機配對成功後開始觀看。

連線後可在檢視器選取攝影機以開啟控制項。多畫面檢視會依目前分頁顯示的攝影機建立串流；暫停或切換分頁可減少頻寬使用。

## 網路與隱私

- PeerJS 的預設訊號服務用於建立連線；影音使用 WebRTC 傳輸。是否能直連取決於裝置、路由器及網路設定。
- 「允許跨網路」會啟用 Google STUN。嚴格 NAT 或企業網路可能需要 TURN 中繼服務；本專案沒有內建 TURN 設定介面，因此這類網路可能無法連線。
- QR 配對連結含短效配對碼，請勿公開分享。配對完成後會保存裝置授權資訊於瀏覽器本機。
- 啟用 ntfy 通知時，動態事件訊息會送至 `ntfy.sh` 上填入的主題。
- QR、掃碼、錄影壓縮與 WebRTC 等函式庫由 cdnjs 載入。首次載入及缺少快取時需要網路；離線安裝不保證所有功能與第三方函式庫可用。

## 錄影與儲存

- 事件錄影保存在攝影機裝置的瀏覽器 IndexedDB，不會自動上傳。
- 可在設定調整偵測靈敏度、忽略區域、事件結束後錄影時間、錄影品質及容量上限。
- 瀏覽器或作業系統可能限制儲存容量，或在清除網站資料時刪除錄影。重要檔案請使用事件頁面匯出備份。
- 更新資料庫結構時會保留既有錄影資料，不應因資料庫版本升級而清空。

## 疑難排解

- **無法使用攝影機／麥克風：** 確認使用 HTTPS 或 `localhost`，並在瀏覽器網站設定允許權限。
- **配對或連線失敗：** 確認兩台裝置均可連上網際網路，重新產生 QR 後再配對；若跨網路仍無法連線，網路可能需要 TURN。
- **離線時功能不完整：** 先在線上開啟一次並讓 PWA 快取完成；第三方函式庫尚未快取時需恢復網路。
- **錄影未儲存：** 檢查瀏覽器可用儲存空間，並在事件頁面刪除或匯出舊錄影。

## 檔案

- `index.html`：應用程式介面與主要邏輯。
- `sw.js`：PWA Service Worker 與離線快取。
- `manifest.webmanifest`：PWA 安裝資訊。
- `icon-192.png`、`icon-512.png`：應用程式圖示。

## 安裝與解除安裝

- 瀏覽器支援時，標題列會出現 📲 安裝按鈕，設定裡也有「App 安裝」區；iOS 需用 Safari 的「加入主畫面」。
- 設定 →「清除資料並解除安裝」只會清除本程式的資料（`pwcam:` 開頭的 localStorage、`pwcam` IndexedDB、`pwcam-` 開頭的快取與本程式的 Service Worker），不影響同網域下的其他 PWA。網頁無法自行移除圖示，清除後請手動刪除。
- 與其他 PWA 共用 `github.io` 網域，因此所有儲存名稱都要加專屬前綴。
